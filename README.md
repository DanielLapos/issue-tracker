# Issue Tracker API

A REST API for managing projects and their issues, built with Java and Spring Boot. This is a work-in-progress portfolio project; the first resource (projects) is implemented, issues come next.

## Tech stack

- Java 25, Spring Boot 4.1
- Spring Web (REST), Spring Data JPA / Hibernate
- PostgreSQL 18, schema managed with Flyway migrations
- Bean Validation for request validation
- MapStruct for entity/DTO mapping
- Maven (wrapper included)
- Docker Compose / Podman Compose for the local database

## Prerequisites

- JDK 25
- Docker or Podman with a compose provider (`docker compose` or `podman compose`)

## Getting started

1. Clone the repository.

2. Create your local environment file from the example and set a password:

   ```bash
   cp .env.example .env
   ```

   The file has a single variable, `DB_PASSWORD`. Both the database container and the application read it.

3. Start PostgreSQL:

   ```bash
   docker compose up -d      # or: podman compose up -d
   ```

4. Run the application (from the project root, where `.env` is):

   ```bash
   ./mvnw spring-boot:run
   ```

   The API is available at `http://localhost:8080`. Flyway creates the database schema on first start.

To stop the database: `docker compose down`. Add `-v` to also delete the stored data.

## API

### Projects

| Method | Path                 | Description          | Success | Errors   |
|--------|----------------------|----------------------|---------|----------|
| POST   | `/api/projects`      | Create a project     | 201     | 400      |
| GET    | `/api/projects`      | List all projects    | 200     |          |
| GET    | `/api/projects/{id}` | Get a project by id  | 200     | 404      |

**Request body (POST)**

| Field         | Rules                       |
|---------------|-----------------------------|
| `name`        | required, not blank, max 100 characters, unique |
| `description` | optional, max 250 characters |

`id` and `createdAt` are generated by the server and cannot be set by the client.

**Example**

```bash
curl -i -X POST localhost:8080/api/projects \
  -H "Content-Type: application/json" \
  -d '{"name":"Website redesign","description":"First project"}'
```

```
HTTP/1.1 201
Location: http://localhost:8080/api/projects/1
Content-Type: application/json

{"id":1,"name":"Website redesign","description":"First project","createdAt":"2026-10-19T08:15:30.123456Z"}
```
